# Código de conduta

Trate as pessoas com respeito. Críticas técnicas e discordâncias são bem-vindas quando se concentram no problema e propõem caminhos para resolvê-lo.

Não são aceitos assédio, ameaças, discriminação, ataques pessoais ou divulgação de informações privadas. Não compartilhe documentos confidenciais de terceiros.

O mantenedor pode moderar conteúdo, encerrar discussões ou restringir participações que violem estas orientações. Para problemas de convivência, procure o mantenedor pelos canais disponíveis no GitHub, sem expor dados pessoais. Para vulnerabilidades, siga [SECURITY.md](SECURITY.md).
